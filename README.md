## 🛠 로컬 실행

```bash
bundle exec jekyll s -l
```

`http://127.0.0.1:4000` 에서 열립니다. (`-l`은 라이브리로드)

### 최초 1회 세팅

Ruby 3.3.x가 필요합니다. (`.ruby-version` 참고)

```bash
rbenv install 3.3.12
bundle install
```

커밋 시에는 husky 훅 때문에 Node 22가 필요합니다. (`.nvmrc` 참고)

```bash
nvm use
```
